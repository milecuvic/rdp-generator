# Promo video (Remotion)

A short promo/intro video for RDP Generator built with [Remotion](https://remotion.dev).

```bash
cd video
npm install
npm start          # open Remotion Studio to preview/edit
npm run render     # renders out/rdp-generator-promo.mp4 (1080p, 30fps)
```

Scenes live in `src/scenes.tsx`; order and timing in `src/Promo.tsx`.
